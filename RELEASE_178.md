Purgatory -NARAKU- PSP 1.7.8 — Test Release
Enri's and Will's stories, ending routes, secret-route events and
bonus areas are implemented. Further hardware and regression testing
is welcome.
Latest changes
- Russian added as a fifth language.
- Translated dialogue, choices, inventory descriptions, menus,
  ending captions and credits.
- Added Cyrillic glyphs and a Russian PSP controls card.
- Save deletion and confirmation available in all five languages.
- Language, ON/OFF and numeric settings values aligned to the right.
- Existing language variants, save files and prior script fixes preserved.
Download
The attached ZIP is an incremental source/resource patch.
It requires an existing port project and a working PSP SDK.
It does not contain a standalone game or a precompiled EBOOT.
Apply the archive and run tools/build_deploy_v178.sh.
Restart the game and use an in-game save after updating.
Testing
