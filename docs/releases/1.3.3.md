# NARAKU PSP v1.3.3 — Development Build

An unofficial PSP port of **Purgatory -NARAKU-**, developed and tested section by section.

## How far does this version go?

The current implementation covers **Maps 001–045**: the opening, early puzzles, flashbacks, chase sequences and the factory section, including metal-sheet interactions, the crank/lift mechanism, key collection and password terminals.

**The full game is not finished. Maps 046 onward are outside the completed implementation scope, and a complete playthrough across all branches and endings is not yet supported and verified.**

## Implemented gameplay

- Movement, running, interaction and item collection.
- Dialogue and choices, animated dialogue windows and colored item names.
- Inventory, key items, notes and translucent menus over the current scene.
- In-game saving and loading.
- Story events, flashbacks and chases in the implemented sections.
- Lasers, traps, death sequences, music and event sound effects.
- Factory puzzles and numeric password input.

## Changes in 1.3.3

- Restored the original capitalization of English item names.
- Kept green, red and gold key emphasis, existing Cleaver emphasis and the metallic-gray Axe pickup text.
- Retained all previous gameplay and asset changes.

Recent cumulative improvements include rebuilt dialogue portraits and expressions for 66 picture assets, corrected metal-sheet interaction selection and revised corridor texture sampling intended to reduce movement shimmer.

## Testing status

This is a development build intended for testing. Host-side checks cover event logic, text and resource handling. They do not guarantee a bug-free playthrough. Final visuals and behavior need further PPSSPP and real PSP testing.

When reporting a bug, include the build version, platform, location, reproduction steps and whether you used an in-game save or an emulator save state.

## Updating

Close PPSSPP before replacing the executable. After updating, fully restart the game and use an **in-game save** or a new run. Older PPSSPP save states can restore code from a previous build.

## What is included?

The repository contains source code, build tools and regression tests. Original and converted game assets, music, XMB artwork, saves and a ready-to-play build are not included. An existing complete local port installation is required for the current testing workflow.

This is an independent fan project. Original game assets remain the property of their respective rights holders.
