NARAKU PSP 1.6.0 - Counter interaction fix

Requires version 1.5.9.
Restores the original RPG Maker counter interaction: when there is no action event directly in front of the player, a tile with the original counter flag allows an action check one tile further. City maps 080-092 now retain this original tileset flag. Old maps without the new optional metadata continue to load normally.
No seller scripts, prices, saves, configuration or story flags are changed.
Stand facing the counter and press the action button. Restart the game and load an in-game save after installation.
Host C syntax and original counter metadata checks passed. PSP and PPSSPP runtime validation remains pending.
